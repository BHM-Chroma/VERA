# VERONIKA Mate

Персонаж на рабочем столе Windows: следит за нагрузкой ПК, отвечает на голос и текст,
выполняет команды и гуляет по экрану — сидит на окнах, в углах, лежит на панели задач.

```
VeronikaMate/
├── godot/     — «тело»: окно с персонажем (Godot 4.5)
├── brain/     — «мозг»: голос, команды, ИИ, мониторинг (Python)
└── release/   — то, что кладётся в готовую сборку (обновлятор)
```
Тело и мозг общаются через `ws://127.0.0.1:8765`. Каждая часть работает и без другой.

## Установка (готовая сборка)
1. Открой страницу **Releases** этого репозитория и скачай `VERONIKA-windows.zip`.
2. Распакуй куда удобно (например, в `Документы\VERONIKA`).
3. Запусти `VERONIKA.exe` — мозг запустится сам.
4. Для ответов ИИ: скопируй `brain\.env.example` в `brain\.env` и впиши ключ OpenAI.

## Обновление
Запусти **`Обновить.bat`** в папке программы. Он скачает последнюю сборку отсюда и
заменит программу, **не трогая** твои файлы: `brain\.env`, `brain\config.local.json`,
память диалогов и лог. Новая сборка появляется автоматически после каждого изменения
кода в ветке `main` (GitHub Actions → вкладка Actions).

## Личные настройки
`brain/config.json` — общие настройки (лежат в репозитории).
Свои ссылки и изменения пиши в `brain/config.local.json` (образец — `config.local.example.json`):
он перекрывает `config.json`, не попадает на GitHub и не перезаписывается при обновлении.

## Разработка (запуск из исходников)
### Тело (Godot)

1. Открой Godot 4.5 → Import → выбери `godot/project.godot`.
2. **Важно:** во вкладке **Game** (сверху) открой меню у кнопки встраивания и **выключи «Embed Game on Next Play»**.
   Иначе игра запустится внутри редактора, и прозрачного окна не будет.
3. Нажми F5.

Управление:
- левая кнопка — перетащить; короткий клик — «тычок»;
- правая кнопка — меню: написать сообщение, состояние ПК, поверх окон, выход.

Окно ловит мышь только рядом с персонажем, остальное пропускает клики на рабочий стол.

### Мозг (Python 3.10+)

1. Дважды кликни `brain/setup_brain.bat` (один раз).
2. Открой `brain/.env` и впиши **новый** ключ OpenAI.
3. Запускай `brain/start_brain.bat`. Всё, что мозг услышал и ответил, пишется в `brain/brain.log`.

Настройки — в `brain/config.json` (свои — в `brain/config.local.json`):

| что | где | варианты |
|---|---|---|
| ИИ | `llm.mode` | `online` (OpenAI), `offline` (Ollama), `auto` (онлайн, при ошибке оффлайн) |
| распознавание речи | `voice.mode` | `online` (Google), `offline` (Vosk) |
| нужно ли имя | `voice.require_wake_word` | `true`: реагирует на фразы с «Вероника», и ещё 10 секунд после ответа |
| свои ссылки | `links` | добавляй по образцу: фразы + адрес |
| пороги тревоги | `monitor` | CPU/RAM в %, температура видеокарты |

### Оффлайн-ИИ (Ollama)
1. Установи Ollama с ollama.com.
2. В терминале: `ollama pull qwen2.5:7b` (≈4.7 ГБ, хватает видеокарты с 6 ГБ).
3. Поставь `"mode": "offline"` или `"auto"`.

### Оффлайн-распознавание (Vosk)
1. Скачай `vosk-model-small-ru-0.22` с alphacephei.com/vosk/models.
2. Распакуй в `brain/models/vosk-model-small-ru-0.22`.
3. Поставь `"voice": {"mode": "offline"}`.

## Прогулки по экрану
Раз в 3–5 минут, пока с ней никто не взаимодействует, она рассыпается пикселями и появляется в другом месте:
- в нижнем углу экрана — стоит (`idle`), сидит (`idle_sit`) или лежит (`idle_lying`);
- на верхнем краю активного окна — сидит (`idle_sit_on_Window`), если окно не развёрнуто на весь экран.
  Окно двигают — едет вместе с ним; окно закрыли или развернули — уходит в угол.

Включить/выключить: меню → «Гулять по экрану» (запоминается), голосом «погуляй» / «стой на месте».
«Переместиться сейчас» в меню — переместиться сразу. Если её перетащить мышкой, она встаёт в обычную позу.
Для сидения на окнах нужен запущенный мозг (без него — только углы экрана).

Настройки (Godot → узел Wanderer, создаётся при запуске): `min_interval`/`max_interval` (сек),
`window_chance` (вероятность окна), `corner_poses`, `seat_pad` (насколько низко сидит на кромке).

## Шейдер

`godot/shaders/toon.gdshader` повторяет ноды из Blender: текстура ×1.5 (Emission 3 × Mix 0.5), ступень света 0.838, диагональная штриховка в тенях.
Цвета приведены к Blender тональной кривой AgX (WorldEnvironment в сцене).
Параметры можно крутить во время игры: Remote → Character → MeshInstance → Surface Material Override.

Лица переключаются костью `cc_facecontr`, как в Blender: X > 1 — говорит, X > 2 — моргает.
Анимируй её в Blender, и выражения поедут в Godot сами. Пока персонаж говорит, рот открывается автоматически.

## Анимации
Код ищет анимации по именам: `idle`, `wave` (клик), `drag` (перетаскивание), `sleep`, `alarm` (перегрузка ПК).
Если анимации нет, персонаж просто остаётся в idle. Добавляй их в Blender и экспортируй тем же способом.
